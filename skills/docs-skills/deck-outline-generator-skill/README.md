> Generates high-impact slide outlines with speaker guidance and per-slide image prompts, tuned for Streamlit plus fal-client generation workflows. Pitch, product, strategy and investor decks.

## Install

```bash
npx skills add https://github.com/buildfastwithai/agent-skills/tree/main/skills/docs-skills/deck-outline-generator-skill
```

<sub>Installs into every agent that reads the <code>SKILL.md</code> format. Add <code>--global</code> to install for all projects, or run <code>npx skills add</code> with no argument to pick interactively.</sub>

## What it does

- Builds a narrative arc before it builds slides
- One idea per slide, with the speaker's job stated
- Per-slide image prompts ready for generation
- Adapts tone: formal, bold, technical, storytelling
- Places proof points where they land hardest

## Try it

Once installed, just talk to your agent in plain language:

> *"Outline a 12-slide seed pitch deck for my AI startup."*

> *"Build a product strategy deck outline with image prompts."*

> *"Turn this doc into an investor narrative with slide-by-slide guidance."*

## What you get back

- ✅ &nbsp;**Slide-by-slide outline**
- ✅ &nbsp;**Per-slide image prompts**
- ✅ &nbsp;**Speaker notes**
