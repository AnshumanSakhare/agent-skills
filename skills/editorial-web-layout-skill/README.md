> Designs narrative, typography-led interfaces inspired by print editorials and modern digital magazines — expressive type, asymmetric grids, and layouts built around reading rather than around components.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add editorial-web-layout-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- Typography as the primary design element
- Asymmetric and broken-grid composition
- Print-inspired vertical rhythm and measure
- Pull quotes, drop caps and editorial furniture done properly
- Storytelling flow across scroll

## Try it

Once installed, just talk to your agent in plain language:

> *"Design a long-form article page with editorial typography."*

> *"Give my blog a magazine layout with asymmetric columns."*

> *"Build a case study page that reads like a print feature."*

## What you get back

- ✅ &nbsp;**Typography-led layouts**
- ✅ &nbsp;**Editorial component set**
