> Fuses vintage computing motifs with modern UX: scanlines, phosphor glow, mono palettes and synth-era typography layered over interfaces that still meet current usability and accessibility standards.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add retro-futurist-web-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- CRT effects — scanlines, glow, chromatic fringe — done tastefully
- Monospace and synth-era type systems
- Terminal and HUD interface patterns
- Nostalgia that doesn't cost you accessibility
- Motion in the vocabulary of old hardware

## Try it

Once installed, just talk to your agent in plain language:

> *"Build a retro-futurist terminal UI for my CLI tool's homepage."*

> *"Give my dashboard an 80s computing aesthetic that's still readable."*

> *"Design a synthwave landing page with CRT effects."*

## What you get back

- ✅ &nbsp;**Retro-tech interface system**
- ✅ &nbsp;**Effect and palette rules**
