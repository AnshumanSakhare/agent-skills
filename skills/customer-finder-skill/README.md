> Turns a startup URL or product idea into a qualified shortlist of potential first customers using recent public pain, demand and timing signals. Every prospect links back to its original source. It drafts openers but never sends anything automatically.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add customer-finder-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- Defines a primary and adjacent ICP from your product, not from a template
- Hunts explicit pain, workaround, switching and timing signals in public discussion
- Scores fit and urgency with the evidence attached
- Links every primary prospect to the original public post
- Drafts a respectful, source-grounded outreach opener
- Refuses private contact enrichment and sensitive personal data

## Try it

Once installed, just talk to your agent in plain language:

> *"Find my first 20 customers for https://example.com."*

> *"Who should I talk to for design-partner interviews for this product idea?"*

> *"Find people publicly complaining about the problem my tool solves."*

## What you get back

- ✅ &nbsp;**Responsive HTML prospect report**
- ✅ &nbsp;**Evidence-linked prospect list**
- ✅ &nbsp;**Draft outreach openers**
