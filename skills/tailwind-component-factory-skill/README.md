> Generates reusable, framework-agnostic UI components using Tailwind and semantic HTML, with keyboard interaction and ARIA handled properly rather than bolted on. Unopinionated enough to compose into your own design system.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add tailwind-component-factory-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- Semantic HTML first, Tailwind classes second
- Full keyboard interaction and ARIA state management
- Headless-friendly API surface you can restyle
- Responsive across your breakpoints by default
- Works in React, Vue or plain HTML

## Try it

Once installed, just talk to your agent in plain language:

> *"Build me an accessible combobox with Tailwind."*

> *"Generate a headless modal primitive I can theme."*

> *"Make this dropdown keyboard-navigable and ARIA-correct."*

## What you get back

- ✅ &nbsp;**Reusable component primitives**
- ✅ &nbsp;**Documented API surface**
- ✅ &nbsp;**Accessibility notes**
