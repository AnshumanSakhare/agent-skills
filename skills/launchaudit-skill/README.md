> Audits a startup from its URL with no founder questionnaire. Reconstructs what the product appears to do, walks the public conversion journey as a first-time visitor, separates observed evidence from inference, and returns a prioritised launch-readiness report with a real verdict.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add launchaudit-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- Figures out what your product does without asking you
- Walks the actual conversion journey on desktop and mobile
- Scores positioning, relevance, conversion, proof, trust, UX, technical surface and ops
- Explicitly separates evidence from inference from unknowns
- Names critical blockers before cosmetic fixes
- Writes the exact copy and interface corrections, then a seven-day repair plan

## Try it

Once installed, just talk to your agent in plain language:

> *"Audit https://example.com before launch."*

> *"Run a deep audit on my site — pricing, docs, trust and conversion paths, desktop and mobile."*

> *"Compare my current site with the redesign at [URL] in before-after mode."*

## What you get back

- ✅ &nbsp;**Standalone HTML report**
- ✅ &nbsp;**Structured JSON source**
- ✅ &nbsp;**Seven-day repair plan**
