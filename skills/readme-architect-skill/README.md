> Builds complete GitHub READMEs that get a stranger from landing on your repo to running it — badges, install, usage examples, architecture notes and contribution guidance, written for onboarding rather than for you.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add readme-architect-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- Opens with what it is and who it's for, in one line
- Install and run commands that are actually copy-pasteable
- Usage examples with real inputs and outputs
- Badges, licence and contribution guidance
- Structured for skim-first reading

## Try it

Once installed, just talk to your agent in plain language:

> *"Write a README for this repo."*

> *"My README is weak — rewrite it for open-source readiness."*

> *"Generate contribution guidance and badges for this project."*

## What you get back

- ✅ &nbsp;**Complete README.md**
- ✅ &nbsp;**CONTRIBUTING guidance**
- ✅ &nbsp;**Badge set**

## Works with

Claude Code &middot; Claude Desktop &middot; OpenAI Codex &middot; Cursor &middot; opencode &middot; anything that reads the [Agent Skills](https://code.claude.com/docs/en/skills) `SKILL.md` format.
