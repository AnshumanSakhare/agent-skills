> Builds frosted, layered interfaces with translucency, a real depth hierarchy and subtle lighting. Premium and atmospheric without turning into an unreadable haze.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add glass-ui-system-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- Layered translucency with a defined z-hierarchy
- Lighting and edge treatment that imply real material
- Contrast maintained so text stays readable on glass
- Motion that respects the spatial model
- Light and dark variants that both hold up

## Try it

Once installed, just talk to your agent in plain language:

> *"Build a glassmorphic dashboard with proper depth layering."*

> *"Design a frosted-glass nav and card system for my app."*

> *"Make this UI feel premium and atmospheric without hurting legibility."*

## What you get back

- ✅ &nbsp;**Glass design system**
- ✅ &nbsp;**Depth and lighting rules**
