> Designs understated, high-end interfaces where precision and restraint do the work — for luxury, fashion, hospitality and premium product experiences that should feel expensive without shouting.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add minimal-luxury-ui-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- Sparse composition with generous negative space
- Premium typography and exact optical spacing
- Refined micro-interactions instead of loud animation
- A tight, disciplined palette
- Detail work that only reads on close inspection

## Try it

Once installed, just talk to your agent in plain language:

> *"Design a landing page for a boutique hotel. Understated and expensive."*

> *"Make this fashion ecommerce site feel high-end and restrained."*

> *"Redesign my product page with luxury minimalism."*

## What you get back

- ✅ &nbsp;**Refined minimal interface**
- ✅ &nbsp;**Spacing and type system**

## Works with

Claude Code &middot; Claude Desktop &middot; OpenAI Codex &middot; Cursor &middot; opencode &middot; anything that reads the [Agent Skills](https://code.claude.com/docs/en/skills) `SKILL.md` format.
