> Builds high-conversion SaaS marketing interfaces with striking visuals, confident typography and a strong CTA architecture — tuned for fast comprehension by a visitor who gives you four seconds.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add bold-saas-marketing-ui-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- Leads with the offer, not the company
- Confident type scale and deliberate visual weight
- CTA architecture designed around one conversion event
- Proof placement: logos, metrics, testimonials where they change the decision
- Fast to scan on mobile

## Try it

Once installed, just talk to your agent in plain language:

> *"Design a SaaS landing page for a developer analytics tool. Conversion event is free trial."*

> *"Make my homepage bolder without losing clarity."*

> *"Build a launch page with strong CTA architecture and social proof."*

## What you get back

- ✅ &nbsp;**Conversion-focused marketing page**
- ✅ &nbsp;**CTA and proof strategy**
