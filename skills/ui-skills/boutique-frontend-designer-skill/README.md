> Transforms standard UI requests into high-concept, production-grade digital experiences. Reaches for a distinct visual identity — Modern Brutalist, Swiss Editorial, Tactile Industrial — rather than defaulting to the component-library look every AI-generated page shares.

## Install

```bash
npx skills add https://github.com/buildfastwithai/agent-skills/tree/main/skills/ui-skills/boutique-frontend-designer-skill
```

<sub>Installs into every agent that reads the <code>SKILL.md</code> format. Add <code>--global</code> to install for all projects, or run <code>npx skills add</code> with no argument to pick interactively.</sub>

## What it does

- Picks and commits to an aesthetic direction before writing markup
- Rejects default component-library styling as a starting point
- Designs the type scale, grid and motion language as one system
- Works across React, Tailwind, Framer Motion or vanilla CSS
- Applies to landing pages, components and complex dashboards alike

## Try it

Once installed, just talk to your agent in plain language:

> *"Build a dashboard for a logistics startup. No generic AI slop."*

> *"Design a landing page with a Tactile Industrial identity."*

> *"Give this React component a distinct visual point of view."*

## What you get back

- ✅ &nbsp;**Art-directed components**
