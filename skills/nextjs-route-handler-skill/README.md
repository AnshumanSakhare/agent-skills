> Builds Next.js 14+ route handlers and server actions that are Edge-runtime compatible, validated with Zod, and defensive about errors and auth from the start.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add nextjs-route-handler-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- App Router route handlers and server actions
- Edge-runtime compatibility checked, not assumed
- Zod schemas for request parsing and response contracts
- Auth and authorisation wired in at the boundary
- Structured errors and observability hooks

## Try it

Once installed, just talk to your agent in plain language:

> *"Write an Edge-compatible route handler for POST /api/webhooks/stripe."*

> *"Convert these API routes to App Router server actions with Zod validation."*

> *"Add proper error handling and auth to my Next.js API layer."*

## What you get back

- ✅ &nbsp;**Route handlers / server actions**
- ✅ &nbsp;**Zod schemas**
- ✅ &nbsp;**Error contract**
