> Takes whatever your repo contains — HTML artifacts, a framework app, a markdown collection, a Python library, notebooks, a CLI — and makes it public-ready: clean structure, a flagship example, a viral README with real proof, a licence, and a distributable agent skill where the repo embodies a reproducible method.

## Install

```bash
npx github:AnshumanSakhare/agent-skills add ship-it-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- Restructures the repo so a stranger understands it in ten seconds
- Builds one flagship example that proves it works
- Writes a README with real proof — screenshots, snippets, demos
- Adds a licence and the missing open-source furniture
- Packages a distributable skill when the repo encodes a method
- Optimises for the five-minute reproduce-it path that turns viewers into sharers

## Try it

Once installed, just talk to your agent in plain language:

> *"Ship it."*

> *"Make this repo public-ready — I want to post it on X tomorrow."*

> *"Clean up this project for open-source release and write the README."*

## What you get back

- ✅ &nbsp;**Restructured repo**
- ✅ &nbsp;**Launch-ready README**
- ✅ &nbsp;**Flagship example**
- ✅ &nbsp;**Licence**
