> Creates bold, anti-polish interfaces with raw typography, hard edges, stark contrast and intentional visual tension — memorable UI that rejects safe defaults without becoming unusable.

## Install

```bash
npx github:buildfastwithai/agent-skills add neo-brutalism-web-skill
```

<sub>Installs into every agent directory found on your machine. Target one explicitly with `--client claude` &middot; `codex` &middot; `cursor` &middot; `opencode` &middot; `project`, or drop it anywhere with `--dir <path>`.</sub>

## What it does

- Hard shadows, thick borders, zero apology
- Raw, oversized typography as structure
- Stark high-contrast palettes
- Intentional friction that still passes usability
- Personality that survives a screenshot

## Try it

Once installed, just talk to your agent in plain language:

> *"Build a neo-brutalist landing page for my indie tool."*

> *"Make this portfolio loud and memorable."*

> *"Give my app a brutalist design system with hard shadows and thick borders."*

## What you get back

- ✅ &nbsp;**Brutalist component system**
- ✅ &nbsp;**High-contrast palette**
